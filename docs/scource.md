# Project Sources & References

This document lists external resources referenced during development, grouped by topic.

	Used for VM provisioning workflows, lifecycle commands, and multi-machine setup.
- **Microsoft Learn**: [Install WSL](https://learn.microsoft.com/en-us/windows/wsl/install)
	Used for WSL2 setup and validation steps on Windows hosts.
- **Microsoft Learn**: [WinRM Portal (FR)](https://learn.microsoft.com/fr-fr/windows/win32/winrm/portal)
	Used for WinRM concepts and remote management reference.

- **GitHub (heyvaldemar)**: [Portainer + Traefik + Let's Encrypt Compose](https://github.com/heyvaldemar/portainer-traefik-letsencrypt-docker-compose/blob/main/portainer-traefik-letsencrypt-docker-compose.yml)
